# NirmAI Design

Single-file design prototypes for NirmAI — design it, fund it, build it.

- **NirmAI-Mobile-v3.html** — every mobile screen, one file (253 tiles): consumer journey, Pro field app, escrow chain. Material 3 tokens (sage seed, light + dark) with the Premium v2 consumer language (Fraunces display, terracotta accent, photo-led heroes).
- **NirmAI-Web-Dashboard.html** — the web dashboard (all roles, demo logins), same token system.
- **NirmAI-Website.html** — marketing site.
- **docs/** — design specs.
- **.claude/harness/** — Playwright persona E2E harness (51 assertions across 8 roles).

Open any HTML file directly in a browser — no build step. Theme toggle (◐) switches light/dark.
